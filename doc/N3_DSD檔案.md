# N3 DSD 檔案

`core/include/daphne/engine/dsd_file.h`、`core/src/dsd_file.cpp`

## 讀取（`DsdFile`）

| 格式 | 支援 |
|---|---|
| DSF，每樣本 1 bit（LSB 先，常見格式） | 讀出時以 256 項查表做位元反轉 |
| DSF，每樣本 8 bit（MSB 先） | 直接使用 |
| DFF（DSDIFF），未壓縮 | 直接使用（本身就是交錯、MSB 先） |
| DFF，DST 壓縮 | 拒絕並回報錯誤 |

- 輸出單位：每聲道每 frame 一個位元組（8 個 DSD bit，最早的 bit 在 MSB），交錯排列。DSD 直送（DoP / 原生 DSD）與 DSD→PCM 都吃這個格式。
- **播放長度以樣本數為準**：DSF 最後一個區塊的補零、資料之後的 ID3 等區塊都不會被當成 DSD 播放。`frames = min(樣本數 / 8, 每聲道可用的位元組)`。DSF 的每聲道可用位元組 = 完整區塊數 × 區塊大小，加上被截斷的最後一個區塊裡最後一個聲道還有的部分（見下方「資料區塊比檔案長」）；DFF 為資料位元組 / 聲道數。
- DSF 以區塊（每聲道 4096 位元組 × 聲道數）為單位按需讀取；搜尋只改位置，下次讀取時才載入區塊。
- DSF 交錯：逐聲道連續複製（來源連續、目的地跨步），比逐 frame 逐聲道的雙層迴圈對快取友善。
- 取樣率：DSD64 … DSD1024（44.1 或 48 kHz 系列的 64 × 2ⁿ 倍），聲道 1–8。
- **標頭的值先檢查、再拿來配置或定位**，損毀或刻意構造的檔案只會讓這一首失敗（錯誤訊息寫出是哪個值）：
  - DSF：`fmt ` 區塊大小 52 B – 1 MiB；每聲道區塊大小 1 B – 1 MiB（格式固定 4096；原本只檢查 ≠ 0，2³¹ 會變成負數、2²⁸ 要配置 2 GB）；`data` 區塊大小至少是它自己的 12 位元組標頭。
  - DFF：每個 chunk 的大小不能超出 form（或它所在的 PROP）的結尾，否則就此停止往下讀；位移每一圈都往前（原本大小 2⁶⁴ − 12 會讓位移回到原處、無限迴圈）。form 大小上限 2⁶²。
  - 資料區塊比檔案長（下載中斷）：以檔案實際的長度為準，播放存在的部分。DSF 的區塊裡聲道一個接一個存放，被截斷的最後一個區塊只播最後一個聲道還有的部分：再往後，前面的聲道還有資料，後面的聲道只剩補上的 0，而 DSD 的 0 是滿刻度的負值，會是一聲爆音。

### 聲道配置

- DSF：channel type 1–7 對應到 WAVEFORMATEXTENSIBLE 遮罩（單聲道 = FC，立體聲 = FL|FR，…，7 = 5.1）。
- DFF：解析 CHNL 區塊的聲道 ID（`SLFT`/`MLFT` → FL、`SRGT`/`MRGT` → FR、`C` → FC、`LFE` → LFE、`LS` → BL、`RS` → BR）。遮罩只能描述遞增位元順序的聲道，所以 ID 必須依此順序出現、不重複、沒有未知 ID，才採用；否則立體聲 / 單聲道用預設遮罩，其他為 0（預設順序）。

## DSD → PCM（`make_dsd_pcm_decoder(out_rate, lowpass_khz)`）

用於不支援 DoP 與原生 DSD 的裝置，以及轉檔。

### 濾波

兩級線性相位 Kaiser 低通（β = 12.26，阻帶 120 dB，DC 增益 1）：

1. **DSD 取樣率**：每 8 個 bit 查一次表。表格 `table[j][byte]` 預先算好 8 個 tap 對 ±1 的加總，所以每個輸出樣本只要 k 次查表相加。通帶到 `pass`，阻帶從 `out_rate − stop` 起（第一個會混疊到最終阻帶邊緣以下的頻率）。
2. **輸出取樣率**：陡峭的 pass → stop 過渡帶（stage 1 已經停在 `stop` 時省略）。

陡峭的部分在低取樣率做：24 kHz 設定、DSD64 時，每個輸出樣本是 23 次查表 + 230 tap，而不是單級的 459 次查表。

| lowpass_khz | 通帶 / 阻帶 | 備註 |
|---|---|---|
| 24（預設） | 24 / 30 kHz | 去除 DSD 在 20 kHz 以上陡升的整形噪聲 |
| 30 | 30 / 60 kHz | DSD64 在 40–50 kHz 約殘留 −58 dBFS RMS 噪聲 |
| 50 | 50 / 80 kHz | |

每項都限制在 0.4535 / 0.5 × out_rate 以內。輸出取樣率預設 176.4 kHz（44.1k 家族 DSD）或 192 kHz（48k 家族），必須整除 DSD 取樣率 / 8。

### 增益

+6.02 dB（×2，併入查表）：DSD 50% 調變（SACD 的 0 dB 參考位準）輸出為 0 dBFS，與同素材的 PCM 版本一樣大聲。超過參考位準的峰值會大於 1.0，由 float64 處理鏈帶到音量級處理。

### 實作細節

- 兩級的歷史緩衝區都用「鏡像」儲存（每個樣本寫兩次，相隔一個長度），所以從寫入點起的視窗永遠連續，內層迴圈沒有取模運算。
- 歷史初值：stage 1 為 DSD 靜音位元組 `0x69`，stage 2 為 0。
- **效能**：stage 2 的核心是對稱的，相對的兩個 tap 先相加再乘一次係數，乘法減半；並以兩個累加器交錯，打斷相依鏈。stage 1 查表以指標遞增定址。
- **搜尋**：重置狀態後從目標之前的位置預先灌入兩級（stage 2 需要目標之前 n2 個輸出，stage 1 再需要那之前 k 個位元組），之後的輸出與從頭讀到該位置完全相同。

### 實際檔案

997 Hz、−30 dBFS 的正弦波經 8 階調變器轉成 DSD64 與 DSD128（DSF 1 bit 含 ID3，及 DFF），再轉回 PCM：

| 項目 | 結果 |
|---|---|
| 長度 | 6 s → 1058400 frames（176.4 kHz），DSD64 / DSD128 皆正確 |
| DSF 與 DFF 的輸出 | 三種低通設定下逐樣本相同 |
| 與重構前的實作比較（對稱摺疊之前） | 渲染成 float32 後差值為 0 |
| 位準 | 24 / 30 kHz：−23.99 dBFS RMS（調變器輸入 −30 dBFS、+6.02 dB 參考增益）；50 kHz：−21.04 dBFS（通帶內包含更多超音波整形噪聲） |
| 速度（單執行緒，24 kHz 設定） | DSD64：38× 即時（重構前 15×）；DSD128：29× 即時 |
