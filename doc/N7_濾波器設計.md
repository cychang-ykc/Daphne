# N7 濾波器設計

`dsp/include/daphne/dsp/filter_design.h`、`dsp/src/filter_design.cpp`

```cpp
std::vector<double> design_lowpass(int taps, int ratio, double fs_in, double fs_out,
                                   double phase, bool apodize, std::vector<double>* lo = nullptr);
```

重取樣與重建用的低通濾波器，全程以 double-double（N8）計算。

- 長度 `L = taps × ratio`（ratio = 整數升頻倍數）。
- DC 增益 1（重取樣器再乘上 ratio）。
- 回傳 hi 部分；`lo` 取得 lo 部分，供高精度卷積使用。

## 原型：Kaiser 窗 sinc

置中、窗在兩端為 0。

| 模式 | 參數 |
|---|---|
| 預設 | 衰減目標 `A = clamp(16·log10(max(Lp, 128)) + 105, 115, 185)` dB；`β = 0.1102·(A − 8.7)`；過渡帶寬 `(A − 7.95) / (14.36·taps)` × 輸入取樣率；阻帶從 0.5 fs_in 開始（截止頻率在 Nyquist 下方半個過渡帶） |
| apodize（`apodize`） | 通帶到 0.4535 fs_in（44.1 kHz 時為 20 kHz），阻帶從 0.5 fs_in 開始；窗在這個過渡帶允許的範圍內盡量窄（β = π·NW，半頻寬 = 1.5 × 過渡帶的一半），所以振鈴很短。ratio 1 時也會套用 |

- ratio 1 且不 apodize：單位脈衝（沒有東西要濾，bit-perfect）。
- 窗函數使用指數縮放的 I0（`e^-x·I0(x)`）：x < 40 用冪級數，以上用漸近級數。長濾波器的 apodize β 可達約 1000，I0 本身在 713 以上會溢位，縮放後沒有這個問題。
- 窗的自變數 `r = n(L − 1 − n) / c²` 以整數乘積精確計算，避免 `1 − x²` 在兩端的相消誤差。

## 相位：部分最小相位

`phase`：0 = 線性相位，1 = 最小相位，介於兩者之間為部分最小相位。

1. FFT 長度 `N = max(65536, nextpow2(8L))`，計算 `0.5·log(|H|² + floor)`，floor = 1e-40（−400 dB，低於任何阻帶）。
2. 倒頻譜：因果部分 × (1 + phase)，反因果部分 × (1 − phase)。
3. 複數 exp，回到時域。
4. **取樣窗位置**：取 L 個樣本，起點在 0 之前 D 個樣本（環狀）。
   - D 取「邊緣位準」在最佳值 6 dB 以內的最小值。邊緣位準 = 窗前 G 個與窗後 G 個樣本最大絕對值中較大者，G = max(L/16, 32)。搜尋範圍 [K, min(N − L, L)]。
   - 最小相位在峰值之前幾乎沒有能量，所以延遲最小者勝出；中間相位則保留較重的尾巴。
   - 低於峰值 240 dB 的位準視為相同。
   - 用單調佇列計算滑動最大值，整體 O(N)。
5. 兩端各 K = min(L/16, 32) 個樣本做升餘弦淡入淡出，重新正規化成 DC 增益 1。

有 phase 時原型只用 75% 的 taps，讓比原型更長的最小相位響應放得進 L。

## 效能

- FFT：
  - 旋轉因子每個大小只算一次，所有級、所有 FFT 共用。
  - 前 14 級在 16384 點的區塊內完成（每塊 512 KB，在快取內），之後兩級融合為一次掃描。
  - AVX2 + FMA3，多執行緒（`parallel_for`，最多「核心數 − 2」）。
- 每個元素的計算方式與單執行緒相同，沒有拆開的歸約：結果與執行緒數無關。
- 逐頻點的 log / exp / sincos 使用快速版本（N8）。

設計時間（16 核心機器）：

| 設定 | 時間 |
|---|---|
| 4096 taps ×4，線性相位 | 6 ms |
| 4096 taps ×4，phase 0.5 | 56 ms |
| 16384 taps ×8（131072 係數），phase 0.5 | 0.38 s |
| 65536 taps ×8（524288 係數），線性 / phase 0.5 | 0.14 s / 2.1 s |

## 取消

設計可能要幾分鐘（1M taps、double-double），停止、換歌、關閉主程式時要能中途放棄（N4「C API 的執行緒」）。

- 合作式取消（`dsp/include/daphne/dsp/progress.h`）：`CancelScope` 把一個旗標掛在目前的執行緒上；`progress()` 與 `check_cancel()` 看到旗標成立就丟 `DesignCancelled`。設計只持有 RAII 資源，丟出後不需要另外清理。
- 旗標屬於這一次的設計：播放器的開始用自己的 `cancel`，背景重建用各自的 `build_cancel`，不需要重設，下一次設計不受影響。
- `parallel_for` 把呼叫者的旗標交給每個工作執行緒，所以每個執行緒都在一個區塊之內停下，而不是跑完自己那一段；工作執行緒的例外（含 `DesignCancelled`）在全部 join 之後由呼叫者丟出。
- 單執行緒的長段落也有檢查：double-double FFT 的位元反轉與旋轉因子表、部分最小相位的迴圈、倍頻 FFT 的第一輪（每個區塊一次）。1M taps × 8 時 FFT 有 2²⁶ 點，原本這幾段在設計開始後約 3 – 9 s 都停不下來。
- 被取消的設計在寫入快取之前就丟出（`design_filter` 在 `store_cached_filter` 之前），所以快取裡不會有設計到一半的濾波器。
- 檢查不改變計算順序：結果與沒有取消檢查時逐位元相同。

## 驗證

### 與重構前的實作比較

taps 1024 / 4096 / 16384 × 取樣率 44.1→44.1 / 88.2 / 176.4 kHz、48→384 kHz × phase 0 / 0.25 / 0.5 / 1 × apodize 開 / 關，共 96 組：hi 與 lo **全部逐位元相同**。

### 頻率響應（`verify/filter_design.py`）

通帶漣波量到 20 kHz（apodize 時到 0.4535 fs_in）；阻帶 = 0.5 fs_in 到 fs_out/2 之間的最高位準。

| 設定 | 通帶漣波 | 阻帶 |
|---|---|---|
| 線性相位 1024 / 4096 / 16384 taps | ≤ 1e-8 dB | −156 / −165 / −173 dB（×4）；×8 再低約 4 dB |
| phase 0.5，不 apodize | ≤ 1.1e-4 dB | −153 ~ −173 dB |
| 最小相位，不 apodize | ≤ 4.5e-4 dB | −155 ~ −178 dB |
| apodize，線性 | ≤ 2e-13 dB | −273 ~ −308 dB |
| apodize，phase 0.5 | ≤ 3e-10 dB | −211 ~ −229 dB |
| apodize，最小相位 | ≤ 3e-10 dB | −210 ~ −310 dB |

- 群延遲（1 kHz）：線性相位為 (L − 1)/2；最小相位約 50–110 個輸出樣本。
- 所有設計的 DC 增益為 1，線性相位的係數完全對稱。
