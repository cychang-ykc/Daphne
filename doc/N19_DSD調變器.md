# N19 DSD 調變器

`dsp/include/daphne/dsp/modulator.h`、`dsp/src/modulator.cpp`、`dsp/src/sdm_tables.inc`、`tools/sdm_design.py`

PCM → 1-bit DSD 的 delta-sigma 迴路。

## 迴路

- **結構**：CIFF（積分器串接、積分器對上的共振回授、前饋到量化器；輸入同時送進第一個積分器與量化器）。
- **係數**：`tools/sdm_design.py` 產生 `sdm_tables.inc`。
  - NTF 用 Schreier 的 synthesizeNTF（最佳化零點、H∞）設計，8 階 DSD64 改用另外最佳化的 NTF（見下方「8 階 DSD64 的 NTF」）；以 CIFF 實現，前饋係數由迴路濾波器的 Markov 參數解出。
  - 再以模擬求出對角狀態縮放：在最大穩定輸入以內，每個狀態的峰值為 1。
- **階數** 5 與 8：5 階超音波雜訊最低，8 階可聽頻段最安靜（預設）。更高的階數只再降低已經遠低於任何 DAC 類比雜訊的可聽頻段雜訊，代價是更多超音波雜訊，所以不提供。
- 依 DSD 倍率（64 … 1024）選表。

| 階數 | DSD | H∞ | 最大穩定輸入 umax | 以 0.5 參考增益換算 |
|---|---|---|---|---|
| 5 | DSD64 | 1.45 | 0.66 | +2.4 dB |
| 8 | DSD64 | 1.4（最佳化 NTF） | 0.74 | +3.4 dB |
| 5 | DSD128 | 1.45 | 0.65 | +2.3 dB |
| 8 | DSD128 | 1.35 | 0.70 | +2.9 dB |
| 5 | DSD256 | 1.3 | 0.80 | +4.1 dB |
| 8 | DSD256 | 1.3 | 0.76 | +3.6 dB |
| 5 | DSD512 | 1.15 | 0.90 | +5.1 dB |
| 8 | DSD512 | 1.15 | 0.90 | +5.1 dB |
| 5 | DSD1024 | 1.1 | 0.94 | +5.5 dB |
| 8 | DSD1024 | 1.35 | 0.70 | +2.9 dB |

8 階 DSD128 的 H∞ 1.35 是依超音波噪聲量測選定的：Scarlet Book Annex D4 要求 40 – 100 kHz < −20 dB re 參考位準，1.35 在有訊號時量到 −31.2 dB，且 SNR 最好。其餘以 −1 / −20 / −60 dBFS 的 SNR 餘量自動挑選。

### 8 階 DSD64 的 NTF

synthesizeNTF 的極點讓 |NTF| 在音訊頻帶之上以最大平坦的形狀升到 H∞。DSD64 時 8 階的上升（約 48 dB/oct）最陡的一段正好在 40 – 100 kHz，原本的 H∞ 1.4 在有訊號時量到 −18.5 dB，不符合 D4；降低 H∞ 也做不到（1.35 / 1.30：−19.8 / −19.1 dB，1.25：−20.7 dB，但 20 – 40 kHz −30 dB、可聽頻段多 24 dB 噪聲，比 5 階還差）。

所以這一組的零點與極點另外最佳化（`sdm_design.py` 的 `optimized_ntf`，以 synthesizeNTF 的結果為起點，SLSQP）：

- 目標：20 Hz – 20 kHz 的噪聲最小。
- 條件：|NTF| ≤ 1.4（與原本相同的 Lee 準則）；40 – 100 kHz 比 synthesizeNTF 低 4 dB；20 – 40 kHz 最多高 3 dB（不讓噪聲堆在 40 kHz 下方）；極點半徑 ≤ 0.98（不做尖銳的共振）。
- 噪聲整形的對數積分（∫ ln|NTF| = 0，Gerzon & Craven）使噪聲只能在頻率之間移動、不能整體壓低（固定的是對數響應的積分，不是噪聲功率本身）：離開 40 – 100 kHz 的噪聲移到 100 kHz 以上（DAC 的類比濾波器濾掉的頻段）。

在處理鏈中量測（44.1 kHz 來源，最差值取自靜音、−60 / −20 / −6 / −1 dBFS 1 kHz 與接近滿刻度的寬頻噪聲；另外 10 kHz、19 kHz、50 Hz、1 kHz + 15 kHz 雙音都在 −23.0 到 −23.6 dB）：

| | 40 – 100 kHz（最差） | 20 – 40 kHz | 可聽頻段 −1 dBFS / 靜音 | umax |
|---|---|---|---|---|
| synthesizeNTF，H∞ 1.4（原本） | −18.5 dB | −60.8 dB | −134.8 / −142.3 dB | 0.70 |
| 最佳化 NTF | **−23.0 dB** | −56.5 dB | −133.0 / −141.4 dB | 0.74 |

處理鏈中（升頻濾波器與限幅器之後）的滿刻度方波、極度壓縮的母帶加 0 到 +12 dB 增益、限幅器天花板上的 50 Hz – 20 kHz 正弦與 10 秒噪聲：狀態限制 0 次、迴路重置 0 次，與原本相同。umax 由 0.70 升到 0.74，限幅器天花板（`0.85 × umax / 0.5`，N18）隨之由 +1.5 dB 升到 +2.0 dB re 參考位準：原本被限幅的最後 0.5 dB 現在直接送進調變器（處理鏈中的上述測試都在新的天花板進行）。

處理鏈不會產生的輸入（沒有頻寬限制、直接送進調變器，3 秒）比原本容易重置迴路：停在限幅器天花板的 40 Hz 方波 410 次（原本 2 – 3 次；停在原本的天花板 17 次）；4 倍滿刻度方波 440 Hz、1 kHz（44.1 kHz 輸入）526 – 1599 次（原本 0 次），50 / 100 Hz 約 2100 次（原本約 1200 – 1300 次），3 kHz 兩者都是 0 次。小直流偏移的 idle tone 與原本相近（音訊頻帶最強的一根由 −162 升到 −155 dB re 參考位準）。

## 輸入路徑

| 步驟 | 說明 |
|---|---|
| 增益 | ×0.5：滿刻度 → 50% 調變（SACD 參考位準） |
| DC 阻隔 | 一階高通，3.5 Hz 轉角（任何輸入取樣率同一個轉角） |
| 輸入削波 | 0.95 × umax（處理鏈的限幅器已經讓訊號低於 0.85 × umax，N18；這裡只是保護） |
| 內插 | 4 點三次 Lagrange 內插到 DSD 時脈 44100 × osr。任意輸入取樣率都可以；鏈送進來的是已經升到 705.6 / 768 kHz 的訊號 |
| 抖動 | 高通 TPDF（相鄰兩個均勻亂數的差），0.01，加在量化器輸入，被 NTF 整形到高頻；每聲道各自的亂數 |

## 保護

- 狀態限制在 ±1.5。穩定範圍內不會碰到（狀態峰值為 1）。
- 一個聲道連續 4096 bit 都有狀態被限制時，視為不穩定，重置該聲道的迴路。
- 計數器：`clamped_bits()`、`loop_resets()`、`input_clips()`，正常為 0。

## 輸出與執行緒

- DSD 位元組，MSB 為最早的 bit，交錯 L R（單聲道只有 L）。
- 立體聲時右聲道在常駐 worker 執行緒上執行。兩個聲道是獨立的迴路，輸出位元組與單執行緒相同。
  - worker 加入 MMCSS「Audio」類別，並沿用呼叫端的 FTZ / DAZ 設定。
  - 每個聲道的狀態各占完整的快取行（`alignas(64)`），避免 false sharing。
- 分批呼叫時，不足一個位元組的 bit 留到下一批，結果與一次處理相同。

## 效能

| 項目 | 做法 |
|---|---|
| 迴路階數 | 樣板參數（`run_channel<N>`），狀態更新與前饋迴圈在編譯期展開 |
| 狀態 | 放在區域陣列（暫存器），每批結束才寫回 |
| 內插權重查表 | 每個輸入樣本的 bit 數是 2 的冪時（705.6 kHz → DSD128 為 8），相位只會是 k/m 這幾個精確值，權重預先算成表；計算與直接算逐位元相同 |

速度（10 秒立體聲、705.6 kHz 輸入、單執行緒）：

| 設定 | 時間 | 即時倍數 | 重構前 |
|---|---|---|---|
| DSD64 5 / 8 階 | 0.84 / 1.27 s | 11.9 / 7.9× | 9.4 / 6.8× |
| DSD128 5 / 8 階 | 1.62 / 2.16 s | 6.2 / 4.6× | 4.7 / 3.6× |
| DSD256 5 / 8 階 | 3.11 / 4.31 s | 3.2 / 2.3× | 2.4 / 1.8× |

快 15–30%；右聲道在第二個執行緒，所以實際立體聲速度約再乘 2。

## 驗證

### 與重構前的實作比較

隨機雙音加噪聲（中間一段 1.4 超量，經過輸入削波路徑）。條件：

- 輸入 705.6 / 352.8 / 44.1 / 88.2 kHz
- DSD64 / 128 / 256
- 5 / 8 階

共 24 組：**輸出位元組全部相同**。速度量測時的輸出也逐位元組相同。
